Install on iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.

Install from your browser

  1. Open the browser menu on this page.
  2. Choose Install app or Add to Home Screen.
  3. Confirm the browser prompt.

If your browser supports a direct install prompt, an install button will appear here. Otherwise, use the browser menu and choose Install app or Add to Home Screen.
